Projects es el panel de gestión de proyectos de la plataforma, al estilo Jira: proyectos con issues, sprints, milestones y tablero.

## Crear un proyecto

1. Abrí [projects.adigitalcafe.com](https://projects.adigitalcafe.com) e iniciá sesión.
2. En el listado de proyectos, tocá **Crear proyecto**.
3. Definí nombre y descripción; podés ajustar el resto después desde la configuración del proyecto.

## Las vistas de un proyecto

| Vista | Para qué sirve |
| --- | --- |
| **Tablero** | Seguimiento kanban de issues por estado |
| **Backlog** | Lista priorizada de trabajo pendiente |
| **Sprints** | Iteraciones con inicio, fin y objetivo |
| **Milestones** | Hitos de alto nivel del proyecto |
| **Calendario** | Fechas de issues, sprints y milestones |

## Invitar al equipo

Los miembros y grupos se resuelven desde Identity: en la configuración del proyecto asigná personas o grupos existentes para que puedan ver y trabajar en él.

> [!info] Para el flujo diario de trabajo, seguí con el tutorial *Trabajar con issues y sprints*.
